---
name: deye-doctor
description: Report D-Eye connector health, capabilities, and surface status.
---

Run these `deye` MCP diagnostic tools and summarise their results:
1. `connector_health()` - which connectors are usable.
2. `capability_list()` - every registered capability.
3. `surface_status()` - which Claude surfaces D-Eye can currently reach.

Report any connector reporting non-usable status with the reason.
